Explorar el mapa

  • Capas y mapas base: activa o desactiva límite, manzanas, usos del suelo, tratamientos y vías. Cambia entre imágenes satelitales y mapa de calles.
  • Navegación: arrastra el mapa para desplazarte; usa la brújula para moverlo o volver al centro de Juan Mina, y el control deslizante o los botones para acercar y alejar.
  • Escala y coordenadas: consulta la escala gráfica y mueve el cursor sobre el mapa para ver latitud y longitud.
  • Divisor: compara los mapas base de imágenes y calles. Cambia la orientación entre vertical y horizontal con el botón que aparece sobre el mapa y arrastra el separador.

Dibujar y medir

  • Punto, línea y polígono: agrega elementos al mapa haciendo clic; termina una línea o polígono con doble clic.
  • Medir: usa la herramienta de medición del mapa para calcular distancias y áreas.
  • Estilo dibujo: selecciona un dibujo y personaliza color, grosor, patrón, relleno y tamaño de punto. También puedes eliminar el dibujo seleccionado.

Analizar y compartir

  • Herramientas GIS: selecciona una capa, ajusta color y transparencia, o clasifícala por un atributo.
  • Etiquetas: elige un shapefile y etiqueta por campo o expresión. Ajusta fuente, tamaño y color del texto; cambia o quita el relleno y el contorno con sus colores y transparencias; define la posición para puntos, líneas y polígonos; filtra con clases y limita la visibilidad por escala. Usa “Mostrar etiquetas de esta capa” para activarlas o desactivarlas.
  • Buffer e intersección: crea zonas alrededor de entidades indicando una distancia en metros, o encuentra el área común entre dos capas.
  • Tabla: consulta atributos, filtra por campo y valor, selecciona resultados y acerca el mapa a ellos.
  • Guardar imagen: exporta la vista actual como PNG o JPG y elige resolución; puedes añadir un título.
  • Limpiar: quita dibujos, mediciones, resultados de análisis y selecciones que agregaste.
También puedes volver a este listado con el botón “Manual”.

Etiquetas de capas

Selecciona una capa y un campo o expresión. El estilo de relleno y contorno se actualiza al cambiar sus controles; pulsa “Aplicar etiquetas” para aplicar el resto de ajustes. Si la capa está apagada, se activará al mostrar las etiquetas.

Combina texto y campos: Python str(properties["nombre"]) + " - " + str(properties["sector"]) · VBScript CStr([nombre]) & " - " & CStr([sector]). También se admite UCase/LCase. No se ejecuta código arbitrario.
